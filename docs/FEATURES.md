# XAJH Helper 功能清单

本文只描述当前生产版本提供的功能及其可用范围。

## 1. 登录与授权

- 支持服务端正式卡密登录。
- 支持本地测试卡 `admin` 手工登录。
- `admin` 每次成功登录后可使用 16 小时。
- 登录后显示当前用户、到期时间和脱敏卡密。
- 正式卡密可使用全部生产功能。
- `admin` 可使用除自动宝箱和云控以外的生产功能。
- `admin` 登录时不创建“自动宝箱”页面，云控开关不可用。
- 功能窗建立后默认选中“快捷设置”。

| 登录类型 | 自动宝箱 | 云控 | 其它生产功能 |
| --- | --- | --- | --- |
| 服务端正式卡密 | 可用 | 可用 | 可用 |
| 本地测试卡 `admin` | 不可用 | 不可用 | 可用 |

## 2. 游戏连接与多开

- 连接当前运行的游戏进程。
- 一键连接多个已运行的游戏窗口。
- 每个游戏进程建立独立的功能窗和运行状态。
- 游戏前台按 `Delete` 可连接未接入的窗口，或重新打开已隐藏的功能窗。
- 支持游戏多开限制处理。
- 连接和桥接未完成时，业务页面保持不可操作状态。

## 3. 快捷设置

快捷设置集中提供账号、识别、挂机、主副控、云控和技能辅助配置。

### 账号与识别

- 查看当前账号和授权到期时间。
- 配置九层妖楼验证码识别密钥。
- 刷新当前连接账号信息。

### 挂机设置

- 按角色数字 ID 独立保存挂机参数。
- 支持普通模式和副本模式。
- 支持设置 1-255 的挂机半径。
- 支持开启或关闭拾取。
- 开启拾取时，组队掷骰自动选择“需求”。
- 关闭拾取时，组队掷骰自动选择“放弃”。
- 支持无技能挂机。
- 支持实验性的丸子挂机。
- 支持副本跳过剧情（被动钩子 PlayCG/PlayBlackEdge；开挂成功后异步装载，不堵内挂）。
- 支持华山“有凤来仪”循环。
- 支持武尊堂“自动降龙”轮流控场编排（按本号已加载技能对象走客户端原生 ActionCast，不依赖快捷栏或外部拼包）。
- 支持设置丸子或有凤循环频率。
- 支持按耐久百分比自动使用工匠修理箱。
- 支持按活力百分比自动使用活力道具。
- 支持保存设置、开启挂机、关闭挂机和刷新实际运行状态。
- 主副控只同步挂机开关，各角色的模式、半径和维护阈值保持独立。

### 挂机启动与关闭逻辑

挂机存在两条不同的启动路径：

| 控制路径 | 开启封包 | 关闭封包 |
| --- | --- | --- |
| 统一挂机开关 | `1500` | `160002` |

“开启挂机”和“关闭挂机”统一通过游戏原始 C2S 发送器直接发送封包，不再模拟 `Alt+R`，也不再按技能是否为空或副本队长身份调用强制挂机函数。角色已经挂机时，助手会先发送关闭封包，再发送开启封包。

### 拾取与组队掷骰逻辑

“开启拾取”当前控制的是挂机期间的组队掉落掷骰策略，不是“自动宝箱”功能。

| 状态 | 实际处理 |
| --- | --- |
| 开启拾取，角色存活 | 开启游戏内挂的“组队自动需求”，由游戏内挂处理“需求” |
| 开启拾取，角色死亡 | 游戏内挂可能不处理掷骰；助手检测到待处理条目后主动发送“需求” |
| 关闭拾取 | 关闭游戏内挂的“组队自动需求”；助手检测到待处理条目后主动发送“放弃” |

- 助手持续检查待处理掷骰，只在出现有效条目时执行需求或放弃。
- 每个条目处理后会标记为已决定，避免同一条目重复发送。
- 开启拾取但死亡状态暂时无法确认时，不会盲目发送“需求”；确认死亡后再处理。
- 角色死亡不影响掷骰守护；自动维修和自动补活力会等到角色复活后执行。

默认挂机参数：

| 配置 | 默认值 |
| --- | --- |
| 挂机模式 | 副本模式 |
| 半径 | 5 |
| 拾取 | 开启 |
| 无技能挂机 | 关闭 |
| 丸子挂机 | 关闭 |
| 副本跳过剧情 | 关闭 |
| 华山“有凤来仪” | 关闭 |
| 武尊堂“自动降龙” | 关闭 |
| 循环频率 | 100 ms |
| 自动维修 | 开启，耐久 50% |
| 自动补活力 | 开启，活力 20% |

挂机模式约束：

- 丸子挂机与华山“有凤来仪”不能同时开启。
- 开启华山“有凤来仪”时会关闭无技能挂机。
- 武尊堂“自动降龙”：在武尊堂副本挂机时勾选，且属于主副控/云控时由主控统一调度，按冷却间隔让参战窗口轮流放降龙十八掌控制怪物；本机群控直接施法，队伍中的跨机成员经队内控/云控定向通知；不适用于加吸星大法配合。
- 副本模式下，队长角色与其他角色使用相同的挂机开关封包。

### 主副控与云控

- 本机窗口可设置为无控、主控或副控。
- 主控支持一键把同机其它窗口设置为副控。
- 支持任务、飞行和挂机开关的业务同步。
- 正式卡密支持按主控名称进行跨电脑云控。
- `admin` 只支持本机主副控，不支持云控。
- 支持队内控：勾选后通过游戏队伍频道文本消息进行主/副控同步，与云控勾选互斥。
  - 主控向队伍频道发送 `[主P]接任务:1111,222` 等命令；副控读取队伍频道执行并回执 `[副G]接pong`。
  - 主控侧提供 PING 按钮：队长发送 `[主P]PING`，队友收到后回 `[副G]PONG`，用于确认是否受控。
  - 聊天发包封包格式为逆向待办（`team_chat.build_team_chat_c2s`）。

### 技能辅助

- 支持协议取消技能后摇。
- 支持单键或按键序列循环。
- 支持按固定策略、忙碌状态或每轮执行取消。
- 支持桥接后台和系统级输入通道。

## 4. 自动宝箱

- 扫描附近指定名称的宝箱目标。
- 对当前目标执行单次开箱。
- 循环扫描、寻路和自动开箱。
- 双击列表中的指定目标执行开箱。
- 支持运行期间的临时黑名单。
- 支持保存和加载固定黑名单。
- 支持查看开箱成功数量和运行状态。
- 仅服务端正式卡密可使用；`admin` 不显示该功能。

## 5. 九层妖楼

- 执行九层妖楼进本流程。
- 识别并处理验证码。
- 启动前检查游戏物理客户区尺寸。
- 支持在需要时调整游戏窗口尺寸。
- 调试关闭时，验证码图片只在内存中处理。
- 提供流程状态、失败原因和停止控制。

## 6. 自动副本

### 活跃模式

- 执行固定活跃副本流程。
- 自动进本、清怪、等待回城和继续下一轮。
- 支持领取活跃宝箱。
- 支持主副控同步相关业务动作。

### 副本模式

- 支持选择目标副本。
- 支持设置运行次数上限。
- 执行进本、清本和回城流程。

### 切糕模式

- 执行对应组队副本流程。
- 支持主号和小号两类角色行为。
- 支持主号与小号独立坐标缓存。
- 支持等待、带入、挂机和超时回城流程。

## 7. 自动任务

- 刷新当前已接任务。
- 按已知任务 ID 接取任务。
- 执行任务交付。
- 执行任务目标寻路。
- 自动推进任务步骤（实验）。
- 配置并运行定时任务队列。
- 校验组队成员和队长状态。
- 支持本机主副控及正式卡密云控同步。
- 提供地图飞行目标选择和执行。
- 通过场景、坐标和附近对象回读任务结果。

## 8. 杂货使用

- 刷新并查看当前背包物品。
- 使用物品或打开可用箱子。
- 按条件自动使用物品。
- 按条件自动出售物品。
- 执行卖满金流程。
- 执行已固化的换牌流程。
- 执行已固化的商城购买流程。

## 9. 鼠标与键盘

### Shift 自由瞄准

- 后台保持 Shift 自由瞄准状态。
- 支持一直按下和单次循环模式。
- 支持配置按下与松开时间。

### 后台按键

- 支持单键、多键和组合键。
- 支持按键轮流连发。
- 支持多个按键同时连发。
- 支持常用按键预设和自定义绑定。
- 支持配置连发间隔和按下时间。

### 鼠标连点

- 支持选择游戏窗口内坐标。
- 支持后台左键和右键连点。
- 支持配置点击间隔和按住时间。

### 前台按键

- 支持多个独立按键槽位。
- 支持单次按下、一直保持和连发模式。
- 支持捕获实际按键作为绑定。

## 10. 系统日志

- 按游戏窗口记录关键操作、运行进度和失败原因。
- 支持按日志类型筛选。
- 支持手工刷新和清空。
- 支持自动滚动到最新记录。
- 调试模式下保存详细开发日志。
- 崩溃和致命错误日志始终写入磁盘。
