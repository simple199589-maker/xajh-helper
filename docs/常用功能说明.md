# 常用功能说明

### 配置复用

- 为了方便用户删除，本配置文件未落盘到用户文件，放在脚本目录`runtime\config`,如果使用新包版本， 可以直接把旧包这个文件夹覆盖进去 就不用再设置一遍用户偏好

### 群控使用

1、正常使用情况下 可先`组队`，因为有队伍才能使用队内控（可跨设备 只要开了助手，不在一台电脑也能群控）

![image-20260827221755843](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20260827221755843.png)

2、`主控`、`副控`、`队内控` 名词解释

1、主控，正常情况下 主控最好是队长，涉及到组队跟随需要队长完成，不允许出现两个主控会导致乱序做任务

2、副控，接受的操作 可以理解为主控(操作号)做什么它就做什么

3、队内控，勾选此选项后 只要是再本队伍 且开启了脚本的都能被控制

> 能做什么? 大概有一键挂机、同步飞行、自动任务这些常用的能力

> 主控开启后影响范围，`组队，组队->取消/关闭挂机，自动整队，召集`、`地图飞行`、`任务列表`、`任务操作`

### 组队能力

![image-20260827222504804](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20260827222504804.png)

1、添加成员，成员需要自行再游戏设置`自动接受组队`，`自动接受跟随`。

2、这里 如果开启了`主控` 则可以自动整队，组好了后会自动再福州集合（但是有个前提 队内控的情况下 需要这些号不在队伍内、本地的群控 则没有这个限制会自动离队）

3、一键开启挂机（通知队内的队员 开启/关闭挂机）、若勾选副本 则是副本挂机、若未勾选则用目标号当前挂机配置

### 计划任务

![image-20260828133944309](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20260828133944309.png)

1、计划任务是可批量执行的 任务步骤 ，配置好需要执行的任务后会步骤执行。

1.1、`前置条件` 群控开启且执行号是主号，若未开群控条件 则建议只执行`日常的5个副本任务`。

1.2、`前置条件` 执行号关联的这几个任务是 已接状态，未接会跳过。

1.3、如果未接任务 可开启群控 切换 `计划`到`自定义`，点击第一个`接日常任务`右键执行，主控开启清空下会通知所有受控端接取。否则就只是本号接

2、定时任务，快捷设置->计划任务 中可设置时间比如 00:35 则是每天这个时候开启执行计划任务.

### 挂机详解

![image-20260828090519746](C:\Users\Administrator\AppData\Roaming\Typora\typora-user-images\image-20260828090519746.png)

> 使用组合设置

1、丸子、无技能挂机

- `内功丸子挂机`、`外功丸子挂机` 根据自己门派攻击属性 勾选后设置 频率目前安全阈值日常`140ms`约350次/分。小日子、武尊堂由于有击飞、击退 建议设置为 `180ms`。每个电脑自己的情况不一样 可酌情调整
- 建议同时勾选`无技能挂机`（注意这里勾选了可能`不会寻路打怪`，如果使用这个建议当`队员`）

2、武尊堂

- 自动降龙，这里是勾选了就参与自动放降龙 建议配合 无技能挂机使用。发起方是主控（这里需要使用群控的能力，由主控自动收集和编排轮到谁放了）
- 不建议丸子号参与因为要放8秒动画 伤害就少了，主要是希望用来小号控怪 减少丸子号被击飞。这样能打更多伤害出来
- 自动开怪，属于实验功能，理论上来说开启了的会寻路到 石碑，自己开怪，排数选0 则挨个开，123 排则只开这几排的，如果多个号开请错开（这样能开的更快）

3、部分副本卡怪忽略

> 若勾选会跳过 组队本的上官霸刀、北疆疯丐的超远仇恨锁定。也可以手动加一些不需要仇恨的怪（贴近还是会打）



### 日常使用步骤

> [!NOTE]
>
> 群控（非群控跳过），快捷设置->任务同步->选主控 ->一键副控。队内控(跨设备-通过队内消息通讯)、不涉及到跨设备的不要勾选

1、配置好组队队友 包括自己（配置一次即可），可以是名称也可以是用户id 比如昵称：张三、李四、王五 ，用户id：8877,7788,9999。首次需要 点击校验队伍获取队友数据 

2、点击自动整队 或者 全部邀请，`这里如果是队内控 需要提前是离队状态`，如果都是本电脑那么直接开启整队即可。

3、高频操作，自定任务->组队->开关内挂 (群控)
