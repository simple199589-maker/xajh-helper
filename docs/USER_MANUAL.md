# XAJH Helper 使用手册

本手册围绕五个核心场景编写：自动组队、飞行棋使用、计划任务、群控（任务同步）、挂机与忽略设置。

## 快速开始

1. 启动游戏并进入可移动的角色。
2. 右键助手，选择“以管理员身份运行”，输入卡密登录；多开用户点“一键登录”。
3. 每个游戏窗口对应一个功能窗，默认打开“快捷设置”。
4. 功能窗的关闭按钮只是隐藏窗口；要停止功能，请回到对应页面点“停止”或“关闭挂机”。

> 登录类型：正式卡密可用全部功能；`admin` 测试卡可用除自动宝箱、云控外的功能，每次登录有效 16 小时。

## 1. 自动组队

入口：功能窗 → 自动任务 → “组队”区域。

准备：

- 当前窗口在“快捷设置 → 任务同步”中选择“主控”（自动整队只对主控开放）。
- 在“成员”框填写队员角色名，可用顿号、逗号或空格分隔。

操作步骤：

1. 点“刷新队伍”：读取当前队伍名单。
2. 点“校验队伍”：把成员名解析为角色 ID；校验通过后，整队和邀请才可用。
3. 点“自动整队”：自动执行“全员离队 → 逐个邀请 → 确认全员实到 → 飞福州”。
4. 需要聚拢时点“召集”：先飞福州，再由当前账号发起组队跟随。
5. “组队跟随 / 取消跟随”可单独使用；“取消/开启内挂”配合“副本”勾选，可向受控窗口同步挂机开关。

注意：

- 本号已在别人队伍时，自动整队会先离队再建队；本号已是队长则保持队长，不会交出队长。
- 整队结果以队伍面板实到人数为准，每一步都会记录到“系统日志”。

## 2. 飞行棋使用（地图飞行）

入口：功能窗 → 自动任务 → “地图飞行”。前提：背包内有“飞行旗”。

操作步骤：

1. 快捷飞行：直接点“飞福州”或“飞师门”。
2. 自选目标：在“页”选择默认页或 0-5 自定义页，在“点”选择具体落点，点“飞行”。
3. 默认页内置三个落点：福州、师门、死亡点；自定义页的落点需要先在游戏内用飞行旗记录。
4. 飞行后有公共冷却，倒计时显示在按钮下方，冷却结束才能再次飞行。

注意：

- 没有记录过的落点无法直接飞；死亡点只能飞真实记录点，不能伪造。
- 群控生效时，页/点选择会同步给副控一起飞行（见第 4 节）。

## 3. 计划任务（定时执行 / 自定义日常）

入口：功能窗 → 自动任务（右侧“计划任务”列表 + 底部执行按钮）；定时开关在“快捷设置 → 计划任务”。

### 3.1 组织队列

1. 左侧任务列表可切换“计划 / 自定义 / 附近 / 已接”四个页签。
2. 在“已接”或“自定义”页右键条目 → “加入计划任务”。
   - 自定义页内置：刷满活跃并领取全部宝箱；霸刀、龙傲天、余沧海、东方不败日常；140 副本任务一/二；组队本；武尊堂。
3. 右侧“计划任务”列表：右键可上移、下移、删除；双击条目直接删除。

### 3.2 执行与保存

1. 点底部“执行计划”按顺序执行队列；运行中可暂停，点“取消”结束。
2. 点“保存”把队列保存到当前角色（按角色 ID 存储，重启后自动恢复）。

### 3.3 每天定时执行

1. 快捷设置 → 计划任务：勾选“启用每天定时”，设置“每天 时 : 分”（默认 10:00）。
2. 到点后，本窗口自动执行一次整个队列；本端是队长时会自然带队。
3. 每个窗口独立计时、独立保存；队列执行期间到点不会重复触发。

注意：

- 日常类预设只处理“已接”的任务：先在游戏内接好日常（或在“任务操作”里输入任务 ID 点“接取”），未接的任务会自动跳过。
- 队列执行过程：寻路 → 挂机打怪 → 确认任务完成 → 停止挂机 → 飞回福州城。

## 4. 群控说明（任务同步）

入口：快捷设置 → “任务同步”。

### 4.1 组网方式

| 场景 | 配置 |
| --- | --- |
| 同机多开 | 一个窗口选“主控”，其它窗口选“副控”；主控可点“一键副控”快速设置 |
| 跨电脑（云控） | 主副控均勾选“启用云控”，并填写相同的“主控名称”（需正式卡密） |
| 无云控条件 | 可勾选“队内控”，通过队伍频道文本同步，与云控互斥 |

- `admin` 测试卡不支持云控，但同机主副控可用。
- 队内控模式下，主控点“PING”可测试队友是否受控（队友自动回 PONG）。

### 4.2 同步内容

- 任务动作：接任务、交任务、任务寻路、领活跃宝箱。
- 地图飞行：飞福州、飞师门、自选页点飞行。
- 挂机开关：统一开启/关闭（含“组队”区的“取消/开启内挂”）。

注意：

- 只同步动作，不同步每个角色的挂机详细参数（模式、半径、阈值等各自保存）。
- 副控收到指令后各自执行；执行结果看各窗口“系统日志”。

## 5. 挂机设置、忽略设置

入口：快捷设置。

### 5.1 挂机设置（按角色独立保存）

推荐顺序：

1. 确认功能窗顶部角色名、地图正确。
2. 选择挂机模式（普通 / 副本）与半径（1-255）。
3. 按需勾选：拾取、无技能、丸子、有凤来仪、武尊堂自动降龙、副本跳过剧情。
4. 设置自动维修（默认耐久 ≤50%）与自动补活力（默认活力 ≤20%）。
5. 点“保存设置” → “开启挂机” → “刷新状态”确认实际运行状态；结束点“关闭挂机”。

注意：

- 丸子挂机与“有凤来仪”互斥；开启有凤会自动关闭无技能。
- 拾取控制组队掷骰：开 = 自动需求，关 = 自动放弃。
- 群控只同步挂机开关，不同步以上参数。

### 5.2 忽略设置（挂机黑名单）

1. 在游戏中选中要忽略的目标（如任务怪、不能攻击的 NPC）。
2. 点“加入当前目标”加入黑名单；名单按目标模板 ID（tid）记录并按角色保存。
3. 在列表中选中条目点“删除选中”可移除；标“(内置)”的条目不可删除。
4. 挂机与副本打怪时，自动跳过黑名单内的目标。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 启动提示需要管理员权限 | 同意提权，或右键“以管理员身份运行” |
| 看不到自动宝箱 / 云控不可用 | `admin` 测试卡的权限限制，换正式卡密 |
| 功能窗关了任务还在跑 | 游戏前台按 `Delete` 重新打开功能窗，到对应页面停止 |
| 自动整队按钮无效 | 确认本窗口是群控“主控”，且成员已通过“校验队伍” |
| 定时到点没有执行 | 检查“启用每天定时”是否勾选；页面忙碌或队列执行中不会重复触发 |
