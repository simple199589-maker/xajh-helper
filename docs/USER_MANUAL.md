# XAJH Helper 使用手册

本文只描述当前正式界面和可交付行为。

## 1. 启动与登录

1. 启动游戏并进入可移动的角色。
2. 右键助手，选择“以管理员身份运行”。
3. 输入卡密。
4. 多开用户选择“一键登录”；单窗口用户可选择“登录”，再把游戏切到前台按 `Delete`。
5. 功能窗建立后默认进入“快捷设置”。

“登录”只完成授权并缩到托盘；“一键登录”还会连接当前已运行的游戏窗口。功能窗关闭按钮只隐藏窗口，不会停止已经运行的业务。要停止功能，必须回到对应页面点“停止”或“关闭挂机”。

### 登录类型

| 类型 | 权限 |
| --- | --- |
| 正式卡密 | 使用服务端授权的有效期；允许自动宝箱和云控 |
| `admin` 测试卡 | 每次登录有效 16 小时；不显示自动宝箱；不连接云控；其它正式页面可用 |

Windows 管理员权限负责连接游戏进程；卡密负责助手功能授权。两者缺一不可。

## 2. 连接与多开

- “一键登录”按顺序连接所有已运行的 `xajh.exe`。
- 游戏前台按 `Delete`：未连接时发起连接，已连接时打开对应功能窗。
- 一个游戏进程对应一个功能窗和一套角色设置。
- “游戏多开”用于放宽游戏自身窗口数量限制，不代表助手可以绕过登录授权。
- 连接仍在进行时，系统日志页可查看进度，其它页面会保持锁定。

## 3. 挂机设置

位置：`快捷设置 -> 挂机设置`。

挂机设置按角色数字 ID 保存到 `runtime\config\hang_prefs.json`。角色名只用于显示，不作为配置主键。重启助手后会恢复该角色最后保存的设置。

### 推荐操作顺序

1. 确认功能窗顶部角色名和地图正确。
2. 选择挂机模式与半径。
3. 设置拾取、技能策略、维修和活力策略。
4. 点“保存设置”。
5. 点“开启挂机”。
6. 点“刷新状态”，确认运行状态、模式和半径。
7. 结束时点“关闭挂机”。

### 配置项

| 配置 | 默认值 | 作用 |
| --- | --- | --- |
| 挂机模式 | 副本模式 | `普通模式` 或 `副本模式` |
| 半径 | 5 | 允许的挂机活动范围，可设 1-255 |
| 开启拾取 | 开 | 开启时处理为需求；关闭时对掷骰执行放弃 |
| 无技能挂机 | 关 | 不使用技能；开关仍使用统一挂机封包 |
| 丸子挂机 | 关 | 实验能力，把攻击类丸子准备到第 3 格并按频率维护 |
| 副本跳过剧情 | 关 | 开挂成功后异步装钩子跳过 CG/黑边（不堵内挂、不轮询） |
| 华山 -> 有凤来仪 | 关 | 华山专用循环，与无技能、丸子模式互斥 |
| 武尊堂 -> 自动降龙 | 关 | 武尊堂 5 人轮流控场编排；不适用于加吸星大法配合 |
| 频率 | 100 ms | 丸子或有凤循环频率，范围 50-60000 ms |
| 自动维修 | 开，50% | 耐久不高于阈值时尝试使用工匠修理箱 |
| 自动补活力 | 开，20% | 活力不高于阈值时尝试使用活力道具 |

### 拾取与掷骰

- 开启拾取且角色存活：开启游戏内挂的组队自动需求，由游戏处理“需求”。
- 开启拾取且角色死亡：助手检测到待处理掷骰后主动发送“需求”。
- 关闭拾取：关闭游戏内挂的自动需求，助手对待处理掷骰主动发送“放弃”。
- 这里的“拾取”控制挂机期间的组队掉落掷骰，不是“自动宝箱”。
- 角色死亡期间仍会维护待处理掷骰；维修和补活力会延后到角色复活。
- 群控只同步挂机开关，不复制每个角色的详细挂机参数。

### 特殊模式

“开启挂机”统一发送 `1500` 封包，“关闭挂机”统一发送 `160002` 封包。该路径不依赖技能是否为空、角色是否为副本队长，也不模拟游戏原生 `Alt+R`。

丸子挂机和“华山 -> 有凤来仪”不能同时开启；开启有凤时还会自动关闭无技能挂机。丸子模式需要背包中存在可识别的攻击类丸子，首次使用应先单角色验证。

“武尊堂 -> 自动降龙”用于武尊堂组队轮流控场：每个参战窗口在武尊堂副本挂机时可勾选；勾选且属于主副控（本机或云控）后，主控窗口统一调度，按“冷却 ÷ 参战人数”的间隔让 5 人轮流放降龙十八掌控制怪物，不追求无缝隙。主控对本机窗口直接施法，对队伍中的跨机成员（队内控/云控）按角色名定向通知，只让目标副控施法。该能力与加吸星大法配合不适用。

副本模式下如果当前角色是队长，启动路径会采用更严格的直接调用与状态回读。出现“开启成功”提示后仍应点一次“刷新状态”，不要只以按钮返回作为运行依据。

## 4. 功能页面

### 自动宝箱

支持扫描、开箱一次、自动开箱、双击指定目标和黑名单。`admin` 测试卡不创建该页面，因此不能启动该功能。

### 九层妖楼

执行进本和验证码流程。启动前会检查游戏物理客户区尺寸；需要调整时会先提示，拒绝或调整失败则不启动。调试关闭时验证码图片只在内存中使用。

### 自动副本

可选择活跃、副本或切糕流程，并设置各自参数。运行期间使用页面“停止”结束，不要通过隐藏功能窗代替停止。

### 自动任务

提供已接任务刷新、已知任务 ID 接取、交付、寻路、定时队列、自动推进、组队校验和地图飞行。系统以场景、坐标和附近对象回读确认结果，不把命令提交本身当作成功。

### 杂货使用

提供背包刷新、使用/开箱、自动使用、自动出售、卖满金，以及已经固化的换牌和商城购买脚本。执行前核对当前角色和数量。

### 鼠标/键盘

提供后台按键、鼠标和组合输入。连接未完成或桥接状态异常时不会开放正式操作。

### 系统日志

显示当前角色的关键操作和失败原因。开启调试后，详细日志写入软件目录 `logs\`；崩溃与致命错误日志始终写入磁盘。

## 5. 主副控与云控

- 同机多开可设置一个主控和多个副控。
- “一键副控”用于快速把其它窗口设为副控。
- 任务、飞行和挂机开关可按业务同步。
- 每个角色的挂机模式、半径、维修阈值等保持独立。
- `admin` 测试卡不建立云控连接，但同机主副控仍可使用。

## 6. 常见问题

### 启动后立即提示管理员权限

同意自动提权，或退出后右键以管理员身份运行。普通权限无法稳定打开游戏进程和全局共享内存。

### 登录后看不到自动宝箱

检查是否使用 `admin`。这是测试卡的预期权限限制，不是界面加载失败。

### 登录后先看到快捷设置

这是正式默认行为，便于先确认角色、挂机参数和主副控身份。需要看连接过程时切到“系统日志”。

### 功能窗关了，任务还在跑

关闭按钮只隐藏。按 `Delete` 重新打开功能窗，再到对应页面停止。

### 挂机参数没有同步到副控

设计上只同步开关，不同步详细参数。请分别打开每个角色的快捷设置并保存。

### 挂机开关

回到快捷设置，使用“关闭挂机”。助手会发送 `160002` 关闭封包。

### 登录失效

正式卡密会按周期向服务端复核；`admin` 从每次成功登录起计算 16 小时。到期后重新登录。
