# 武尊堂自动开怪正式能力（2026-08-26）

## 目标

挂机开启且场景为 `1255` 或 `1541` 时，进入本次副本后只执行一次自动开怪。

## 动态对象识别

正式路径优先调用桥命令：

```text
CMD_OBJECT_SCAN = 56
BRIDGE_BUILD_ID = 2026082603
```

桥命令在游戏 UI 线程只读扫描：

- `CLASS_NPC = 2`
- `CLASS_MATTER = 1`
- 名称：`真·武尊堂挑战牌`

返回共享内存字段：

- `id_lo/id_hi`：实时 `obj_id64`
- `tid`：当前模板 ID，仅用于诊断
- `x/y/z`：对象坐标
- `err`：扫描结果和动态字段日志

桥命令不调用 UI 交互、不按键、不发送封包。

## 对话组包

当前会话找到有效 `obj_id64` 后，取：

```text
field = obj_id64 & 0xFFFF
```

按以下结构生成两帧：

```text
0A00 + little-endian(field) + 010000000001
0C00 + little-endian(field) + 010000000001
```

示例：

```text
obj_id64 = 0x1000000000119BC
field     = 0x19BC

0A00BC19010000000001
0C00BC19010000000001
```

对话两帧间隔 200ms。任一发送失败，停止后续动作，不发送开怪包。

## 开怪序列

对话发送成功后执行通用开怪序列：

- `0`：三排全部执行
- `1`：第一排 5 个
- `2`：第二排 5 个
- `3`：第三排 6 个
- 每包间隔 1 秒
- 当前会话完成后停止，不循环执行

## 失败保护

以下情况立即停止且不盲发：

- 场景不是 `1255/1541`
- 实时挂机未开启
- 找不到挑战牌
- `obj_id64` 无效
- 桥命令失败且 Python 回退扫描也失败
- 对话包发送失败
- 进程断开、场景离开或停止挂机
